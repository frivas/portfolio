Active Profile: personal

One machine.
Many Git identities.

A small Go CLI that stores your personal, work and client Git profiles and swaps your global name, email and SSH signing key in one step.

InstallSource
  ~ go-git-swap

    

  


  

    
// what it handles

    

      
Profiles
Name, Git user name, username and email per identity, stored in ~/.go-git-swap.json.

      
One-step switch
Pick a profile number; your global Git config is rewritten for you.

      
SSH commit signing
Attach a public key and it sets gpg.format=ssh, the allowed-signers file and commit.gpgsign.

      
Validation
Rejects malformed emails before they ever reach your commits. macOS and Linux.

    

  


  

    
// install


$ go install github.com/frivas/go-git-swap/cmd/go-git-swap@latest
$ go-git-swap

    
Or grab a binary from GitHub Releases. After switching, git config --global --list shows:


user.name=Ada Lovelace
user.email=ada@home.example
gpg.format=ssh
commit.gpgsign=true
